# Знакомство с sequentialist-agentic

[English](overview.md) · Русский

## Какую задачу решает пакет?

`sequentialist-agentic` — прикладное ПО, которое связывает действия инструментов,
поиск информации и построение выводов с поисковыми алгоритмами семейства.
Задача может требовать ответа из источников или вывода из известных посылок.
Приложение определяет смысл фактов, действий, целей и проверок результата.

| Какой пример выбрать | Входные данные | Результат |
|---|---|---|
| Исходный пример агента с инструментами | Имитация поисковых запросов, фрагментов текста и оценок, ограничения ресурсов | Шаги, затраты ресурсов и результат обхода агента |
| Конечный пример геометрического вывода | Явные символьные факты и доверенные правила следования | Проверенная последовательность применений правил, условный результат или причина остановки поиска |
| Ограниченный поиск по источникам | Документы с идентификаторами источников и заданная вызывающим кодом функция извлечения | Ответ с идентификаторами источников, числом просмотренных документов и причиной остановки |

Математические алгоритмы находятся в `sequential-search`. Представления графов,
которые не изменяют данные, — в `sequentialist-visuals`. Другим предметным пакетам
не обязательно подключать это приложение, чтобы использовать поиск или игры.

## Что может сделать человек без навыков программирования

Начните с конкретного вопроса и уже известных материалов. Определите, какой
результат считаете приемлемым: цитату из источника, проверенное применение
правила или предметное решение. Ассистент или разработчик может сопоставить
задачу с примерами, выполнить их и объяснить полученный результат.

В текущем геометрическом примере приложение явно задаёт факты о равнобедренном
треугольнике и середине основания, затем применяет небольшой набор доверенных
правил, чтобы показать перпендикулярность медианы основанию. Без факта о середине
остаётся условие с недостающей посылкой. Пример показывает механизм рассуждения;
он не разбирает произвольные чертежи и не решает автоматически олимпиадные задачи.

Для поиска предоставьте документы с разными идентификаторами источников и
укажите, какой текст считается ответом. Пример сообщает, из какого источника
получено подходящее утверждение. Проверка надёжности источника и истинности
утверждения — отдельная задача.

В этой версии нет пользовательского интерфейса без программирования или
размещённого поискового сервиса. Примеры работают без сети и не требуют ключа
LLM. Их исходники и описание ожидаемого поведения можно читать без установки
Python; для выполнения нужны Python и описанные зависимости разрабатываемой версии.

## Запуск текущих примеров

Текущие [метаданные пакета](../pyproject.toml) закрепляют проверенный коммит
`sequential-search-core` — `45fbe4cdba647b59ec3fd528cad94019cece3ba9`, содержащий
`sequential_search.reasoning`. Коммит опубликован в ветке для ревью, но пока не
включён в основной выпуск исходной библиотеки. Выполните из корня agentic:

```bash
python -m pip install -e '.[dev]'
python examples/search_agent_demo.py
python examples/reasoning_demo.py
python -m pytest -q tests
```

При совместной локальной разработке можно необязательно заменить закреплённый
пакет соседней рабочей копией: `python -m pip install --no-deps -e ../sequential-search`.
После такой замены повторно проверьте совместимость примеров.

Пример выводит результаты прямого, обратного и двунаправленного поиска, а также
найденный ответ с идентификаторами источников и числом просмотров. Конечные
последовательности вывода проверяются алгоритмом исходной поисковой библиотеки.
Точный печатный вывод может меняться с поддерживаемой разрабатываемой версией;
проверяйте статус результата и его предпосылки.

Для необязательного HTML-представления без сетевых зависимостей:

```bash
python -m pip install -e ../sequentialist-visuals
python examples/reasoning_demo.py --html reasoning-proof.html
```

Откройте `reasoning-proof.html` в браузере. Страница показывает переданные записи
и не добавляет новых гарантий корректности или статистических гарантий.

Исходный [search_agent_demo.py](../examples/search_agent_demo.py) остаётся
отдельным от нового [reasoning_demo.py](../examples/reasoning_demo.py). Оба
используют объявленную версию зависимости; соседняя рабочая копия исходников
не обязательна для запуска без внешних сервисов. Доступность коммита и статус
его включения в выпуск — разные свойства.

## Текущие возможности и ограничения

В текущих разрабатываемых исходниках реализованы:

- Адаптеры инструментов и узлов, а также базовый обход с имитацией внешних инструментов.
- Заданный приложением конечный набор геометрических правил.
- Интеграция с прямым, обратным и проверяемым двунаправленным поиском вывода.
- Ограниченный поиск в документах в памяти с идентификацией источников и обработкой повторов.
- Необязательное HTML-представление доказательства через visuals без изменения данных.

Универсальный автоматический доказатель, проверка математических рассуждений на
естественном языке, промышленный веб-поиск, универсально откалиброванный
LLM-оценщик и полная схема контроля ошибок всего адаптивного поиска не
реализованы. Для исполнения реальных инструментов и промышленной эксплуатации
нужны дополнительные инженерные адаптеры и явные контракты исполнения и
восстановления. Сроки появления этих возможностей не заявлены.

## Частые вопросы

**Почему не разместить здесь все алгоритмы?**
Это прикладной слой. Повторно используемая математика и кибернетика относятся
к `sequential-*`, программная инженерия и предметная семантика — к `sequentialist-*`.

**Доказывает ли успешный конечный вывод произвольное математическое утверждение?**
Нет. Проверяющий алгоритм проверяет применения правил при заданных фактах,
правилах и контексте. Корректность предметных правил и истинность посылок остаются
явными предположениями. Условный результат или остановка по бюджету не являются
безусловным доказательством.

**Являются ли оценки уверенности LLM e-values с гарантией ошибки?**
Не автоматически. Валидный e-процесс требует заявленной статистической модели
или условий калибровки. Для контроля FWER/FDR всего поиска также нужны
обоснованные правила адаптивного выбора, учёта зависимостей и бюджета.
Имитирующий оценщик и произвольные числовые оценки не устанавливают эти условия.

**Устанавливает ли ответ со ссылкой на источник истину?**
Он устанавливает, что сообщалось в принятой записи источника. Функцию извлечения
и критерий принятия задаёт вызывающий код. Исчерпание источников и достижение
лимита документов не доказывают, что ответа не существует.

**Почему имя для установки отличается от имени импорта?**
Репозиторий называется `sequentialist-agentic`, текущие метаданные называют
дистрибутив `sequential-search`, а Python-импорт — `sequentialist_agentic`.
Это текущее состояние метаданных; документ не переименовывает пакет.

**Могут ли Codex, Claude, Qwen, Gemini, Grok или Perplexity использовать эти материалы?**
Они могут использовать источники, к которым имеют технический и разрешённый
доступ. Инструменты для программирования по-разному обнаруживают `AGENTS.md`
и файлы-указатели для отдельных клиентов. При необходимости передайте ассистенту
этот обзор, [README](../README.md) или [указатель материалов](../llms.txt) явно.
Веб-ассистенты вроде Grok или Perplexity могут читать доступные страницы
репозитория; индексация, позиции в выдаче, цитирование и автоматическая поддержка
файлов не обещаны этим репозиторием.
